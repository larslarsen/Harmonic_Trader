## Objective

Implement the label-free preprocessing boundary between immutable
`MultimodalVector` events and later unsupervised models. Fit geometry and
microstructure transforms on training rows only and emit matched FULL, MICRO, and GEOMETRY
matrices for the same canonical event keys.

This task does not select a clustering algorithm and does not inspect outcomes.

## Required API and Semantics

Names may vary only when needed for clarity, but the public behavior must include:

1. A frozen configuration with strictly positive finite geometry and microstructure block
   weights.
2. A canonical event key containing instrument id, decision time, and terminal pivot
   sequence.
3. A fitted immutable artifact recording:
   - exact geometry and microstructure feature-name order;
   - per-column training median;
   - per-column training IQR using NumPy's explicit linear quantile method;
   - constant-column masks;
   - normalized block weights;
   - fit-row keys or their deterministic SHA-256; and
   - deterministic canonical serialization and SHA-256 identity.
4. A fit function accepting only a non-empty sequence of `MultimodalVector` training
   rows and configuration. Its API must have no labels, returns, MFE, MAE, P&L, direction,
   or outcome argument.
5. A transform function that applies the frozen artifact without refitting and returns one
   immutable matched object containing:
   - canonical, unique event keys sorted by
     `(decision_time_us, instrument_id, terminal_sequence)`;
   - FULL, MICRO, and GEOMETRY float64 matrices;
   - identical row order/count across all three matrices; and
   - exact feature-name schemas for each matrix.
6. Median centering and IQR scaling are fitted independently per block. A zero-IQR column
   uses scale 1 and remains recorded as constant. A block with every column constant fails.
7. After robust scaling, divide each block by the square root of its nonconstant dimension.
   For FULL, normalize the two configured positive weights to unit Euclidean norm, apply
   them to their blocks, and concatenate geometry then microstructure. For single-block
   ablations, use the dimension-normalized block at unit weight.
8. Reject duplicate event keys, empty training/transform inputs, inconsistent feature
   names/order, non-finite values or float64 conversion, non-finite fitted statistics,
   incompatible artifact schema/version, and mutation attempts.
9. NumPy arrays returned to callers must be C-contiguous and read-only. The fitted artifact
   must store immutable tuples rather than mutable arrays.
10. Transforming validation/test rows, including extreme future rows, cannot change the
    fitted artifact or earlier transformed rows.

The implementation may depend on NumPy, already declared in the `research` extra. Do not
use scikit-learn in this task.

## Required Test Source

Tests must prove at least:

- exact training medians/IQRs and linear-quantile behavior;
- separate block fitting and declared block weighting;
- matched canonical keys and matrix row order;
- validation/test data cannot influence fitted statistics;
- invariance when an economic feature and its training sample are rescaled/translated;
- deterministic artifact bytes/hash and parse/round-trip if parsing is exposed;
- duplicate keys, schema drift, empty input, invalid weights, NaN/infinity/float overflow,
  and all-constant blocks fail closed;
- zero-IQR columns are recorded and do not divide by zero;
- outputs are float64, C-contiguous, and read-only; and
- geometry-only and micro-only matrices contain no columns from the other block.
