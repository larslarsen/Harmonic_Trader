## Required Custom-Data Contract

### 1. One stable registered envelope

Define one frozen, slotted pure-Python payload class with stable type name
`HarmonicObservationData`. It must expose non-boolean unsigned-64-bit `ts_event` and
`ts_init` nanosecond values and an immutable canonical observation payload plus its
lowercase SHA-256.

Its Arrow schema must use explicit types and contain, at minimum, these non-null fields:

- canonical payload text as `string`;
- payload SHA-256 as `string`;
- `ts_event` as `uint64`; and
- `ts_init` as `uint64`.

Implement the rc3 pure-Python registration protocol:

- `type_name_static()`;
- deterministic `to_json()`;
- validating `from_json()`;
- `encode_record_batch_py()` returning a record batch in the exact declared schema; and
- `decode_record_batch_py()` that reconstructs only validated immutable payloads.

Expose an explicit idempotent registration entry point. Importing the top-level
`harmonic_trader` package must not require the optional Nautilus dependency or mutate a
global registry. Every construction and decode boundary must validate field types,
timestamp range, canonical form, and payload hash.

### 2. Explicit semantic codec

Support every existing member of `CausalObservation` through an explicit whitelist:

- `MarketBarObservation`;
- `TradeFlowObservation`;
- `OpenInterestObservation`;
- both realized and indicative `FundingObservation` variants;
- `BasisObservation`;
- `LiquidationObservation`; and
- `CostCalibrationObservation`.

The canonical UTF-8 JSON must carry a schema version, explicit observation-type tag,
every dataclass field, complete `ObservationMeta`, and complete `ReleaseLineage`. Use
sorted keys, compact separators, no NaN/infinity, and no dynamic class import or generic
object hook. Encode every `Decimal` as its exact string representation and reconstruct
through the existing domain constructors so their financial-semantic validators run
again. Preserve realized versus indicative funding, effective/availability/retrieval
times, units, lineage, censorship booleans, and valid economic zeroes exactly.

The codec must reject unknown/missing/extra keys, unknown schema or observation tags,
invalid enum values, noncanonical payload text, invalid hashes, and any payload that does
not reconstruct to the same canonical bytes. It must never coerce decimal data through
binary float.

### 3. Causal Nautilus mapping

For a validated observation with known source availability:

```text
ts_event = event_time_us * 1_000
ts_init  = source_available_at_us * 1_000
```

Reject unknown `source_available_at_us`, booleans, negative values, and multiplication
outside the unsigned-64-bit nanosecond range. `retrieved_at_us` and funding
`effective_time_us` remain distinct payload facts; neither substitutes for
`ts_init`.

Construct `DataType` with:

- type name `HarmonicObservationData`;
- metadata containing only string values for `schema_version="1"`, exact product value,
  and exact instrument id; and
- a deterministic identifier derived from schema version, product, and instrument id so
  independent catalog partitions cannot collide.

The identifier derivation must be delimiter-safe and tested. Routing equality is defined
by the type name and metadata; the identifier is persistence identity only. Wrapper
decode must fail closed unless outer type name, metadata, identifier, timestamps, and
inner canonical payload all agree.

Expose a deterministic batch preparation function that rejects an empty input and
duplicate `(product, instrument_id, event_time_us, source_available_at_us)` identities,
then returns wrappers in total order by:

```text
(ts_init, ts_event, product value, instrument id, payload SHA-256)
```

This total order makes ties deterministic before Nautilus applies its stable `ts_init`
sort. Do not mutate caller observations or returned payloads.

### 4. Strategy-clock guards

Implement small dependency-light guards, not a production `Strategy` subclass. They must
validate non-boolean unsigned-64-bit nanosecond values and prove these relations:

```text
observation ts_init <= strategy callback clock
multimodal availability <= decision time <= strategy callback clock
decision time + strictly positive declared latency <= submission clock
```

Convert the existing `MultimodalVector` microsecond clocks to nanoseconds with checked
arithmetic. Reject a zero/negative latency, a same-decision submission, clock regression,
or overflow. Keep economic decision time, callback time, and planned/actual submission
time separate; do not silently replace one with another.

No order side, quantity, price, fill, fee, funding cashflow, position, P&L, label, return,
MFE, MAE, cluster, or model concept belongs in these modules.

## Required Test Source

Tests must use deterministic synthetic contract fixtures only and prove at least:

1. every current observation variant round-trips through the explicit semantic codec
   with exact `Decimal`, lineage, clock, zero-value, funding-kind, and censorship facts;
2. canonical bytes and SHA-256 are stable across repeated construction and independent
   of input mapping order where a mapping is accepted;
3. `CustomData.to_json_bytes()` / `from_json_bytes()` reconstruct the registered payload
   and exact `DataType` identity;
4. Arrow encode/decode and a clean temporary `ParquetDataCatalog` round-trip reconstruct
   the exact wrapper/payload identities for multiple products and instruments;
5. catalog writes are supplied in ascending `ts_init` order and queried custom wrappers
   are replayed through the low-level engine API, not `BacktestDataConfig`;
6. unknown availability, timestamp overflow, malformed/noncanonical JSON, unknown or
   extra fields, tampered payload/hash, invalid domain data, metadata/identifier/product/
   instrument mismatch, wrapper timestamp mismatch, empty batches, and duplicate causal
   identities fail closed;
7. a test-only `Strategy` subscribes in `on_start`, receives real `CustomData` in
   `on_data`, validates delivery with the production guard, and records the actual
   `self.clock.timestamp_ns()` without placing orders;
8. intentionally reversed unique-`ts_init` input delivered through
   `BacktestEngine.add_data(..., sort=True)` is observed in ascending `ts_init` order and
   each simple fixture callback clock equals its `ts_init`;
9. an older economic event published later cannot appear in, mutate, or retroactively
   revise the probe's earlier immutable decision evidence; and
10. multimodal decision and positive-latency submission guards accept exact valid
    boundaries and reject early callbacks, same-time submissions, regressions, invalid
    types, and overflow.

Configure the test engine with logging bypassed and analysis disabled. Dispose it in a
`finally` path. Do not add a venue, instrument, execution client, order, or fill merely to
test custom-data clocks.

Tests must not read real data, inspect outcomes, use a network, rely on wall-clock time,
or write outside pytest-managed temporary directories.
